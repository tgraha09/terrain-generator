# Mixanimo Pro 🎬

**Mixanimo Pro** is a powerful Blender add-on that lets you easily merge, edit, and export animations downloaded from Mixamo.  
It simplifies your animation workflow, eliminates repetitive manual tasks, and provides game-engine-ready outputs (Unity, Unreal Engine).

---

## ✨ Features

- **Action Management**
  - Load, reorder, and merge Mixamo animations.
  - Support for loops (repeat) and overlaps.

- **Bake & Stabilize**
  - Bake animations into a single clean action.
  - Optional root motion stabilization.

- **FBX Export Button**
  - One-click clean FBX export.
  - Presets: Unity (`-Z Forward / Y Up`) and Unreal (`-Y Forward / Z Up`).
  - Removes unnecessary leaf bones automatically.

- **User-Friendly UI**
  - All tools in 3D View > Sidebar > Mixanimo Tools.
  - Fully compatible with Blender 3.5+ and 4.x.

---

## 📦 Installation

1. Download `Mixanimo_Pro.zip` from [Gumroad](https://mixanimo.gumroad.com).
2. In Blender → `Edit > Preferences > Add-ons > Install...` and select the zip file.
3. Enable the add-on in the list.
4. Access it in 3D View → `N` panel → **Mixanimo Tools** tab.

---

## 🚀 Usage

1. **Load animations** → Import FBX animations from Mixamo.
2. **Send to timeline** → Arrange them sequentially or overlapping.
3. **Bake to Action** → Convert into a single action.
4. **Export FBX** → Get optimized output for your game engine.

---

## 🛠 Requirements

- Blender 3.5 or later  
- Mixamo characters (T-Pose recommended)
